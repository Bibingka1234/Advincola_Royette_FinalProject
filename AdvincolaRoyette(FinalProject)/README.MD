# Student Task & Expense Manager CLI

## Description
A command-line Python application designed to help students manage daily tasks and track expenses efficiently.

## Features
- Add tasks
- View tasks
- Mark tasks as completed
- Add expenses
- View expenses
- Display highest expense
- File-based data storage using JSON

## Python Concepts Used
- Object-Oriented Programming
- File Handling
- Lists and Dictionaries
- Sorting Algorithms
- Lambda Functions
- Error Handling
- Data Processing
